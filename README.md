Tell cx what to do and when, such as summing up yesterday's orders at 9 every morning, and cx keeps it as a scheduled job and does it on time, in the conversation where you asked. Your store's data needs Amazon SP-API.

Some things you can ask:

- At 9 every morning, sum up yesterday's orders and sales in each marketplace.
- Check B0EXAMPLE1's Buy&nbsp;Box every hour, and tell me if someone takes it.
- Remind me every Friday afternoon to look at the ads report.

## When jobs run

Jobs run only while cx's computer is on, that is, while you use cx or after you turn on Keep it on in Settings. If cx's computer is off when a job falls due, the job doesn't run and doesn't switch it on, and the missed run isn't made up once it's back on. A job set to run once never runs if it's missed. Jobs stay after cx's computer switches off.

## What it costs

You pay for the time cx's computer is kept on, and a job that runs often keeps it on.

## What it needs

It needs pi-task-scheduler, which Plugins installs with it.
