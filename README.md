Ask cx to do something at set times, such as checking your listings' Buy Box every hour, and cx keeps it as a scheduled job, which stays after cx's computer switches off.

## When jobs run

Jobs run only while cx's computer is on, that is, while you use cx or after you ask cx to keep it on. If cx's computer is off when a job falls due, the job doesn't run and doesn't switch it on.

## What it costs

You pay for the time cx's computer is kept on, and a job that runs often keeps it on.
